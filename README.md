# What is Nurgle's Garden?

Nurgle's Garden is a living software project documenting the journey from beginner programmer to cybersecurity professional.

Inspired by grimdark aesthetics, gothic architecture, and the philosophy of continual growth, the Garden transforms personal development into an evolving fortress where every lesson learned, project completed, certification earned, and milestone achieved strengthens the world around it.

Rather than creating disconnected tutorial projects, every concept learned contributes to one continually evolving application.

---

# Why This Project Exists

Most beginner repositories only showcase finished code.

Nurgle's Garden preserves the entire journey.

Every feature is documented.

Every bug becomes a lesson.

Every milestone represents genuine growth.

The goal is not simply to build software, but to document the process of becoming the kind of developer capable of building it.

# ⚔ Development Philosophy

Nurgle's Garden follows three guiding principles.

- Learn every concept before moving forward.
- Document everything worth remembering.
- Build software that tells a story.

Every feature is developed one lesson at a time.

Every bug becomes knowledge.

Every release represents genuine growth.

---

# 🏛 Project Principles

The Garden is built according to five principles.

1. Understand before copying.
2. Build one feature at a time.
3. Document every important lesson.
4. Leave the code cleaner than yesterday.
5. Growth is measured by understanding, not by the number of files written.
