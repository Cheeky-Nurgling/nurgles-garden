# 📖 Codex Viridis

> *"Knowledge, like the Garden, grows one lesson at a time."*

Welcome to the official programming handbook for **Nurgle's Garden**.

The Codex Viridis documents every concept learned while building this project. Rather than collecting random notes, it is organized as a living textbook that grows alongside the Garden.

Every chapter is based on real features, real challenges, and real lessons learned during development.

---

# Purpose

The Codex exists to help you:

- Understand every concept before moving on.
- Build confidence through repetition.
- Create a permanent reference for future projects.
- Learn software development through practical examples.
- Document your journey from beginner to developer.

---

# How to Use the Codex

Each chapter follows the same structure:

- 📚 What You'll Learn
- 🌿 Why It Matters
- 💡 The Lesson
- 🏰 Examples from Nurgle's Garden
- ⚠️ Common Mistakes
- ✅ Best Practices
- 📝 Practice Challenge
- 🌱 Nurgling Notes

Read the chapters in order the first time through.

Afterward, use the Codex as a reference whenever you need a refresher.
